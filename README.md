# C++ University Practice Repository

This repository contains a collection of practice exercises aimed at reinforcing C++ programming concepts. It is organized into two main sections: **Basic** and **Advanced** topics.

## 📂 Basic Topics

### 1. Basic Actions
Introduction to the fundamental building blocks of C++.
* Primitive data types (int, float, double, char, bool).
* Arithmetic operations and precedence.

### 2. Conditional Structures
Control flow and decision making.
* `if`, `else`, `else if` statements.
* `switch` case structures.
* Binary and comparison operators (`&&`, `||`, `==`, `<`, `>`, `<=`, `>=`).

### 3. Loops
Iteration and repetitive tasks.
* `for`, `while`, and `do-while` loops.
* Nested loops examples.

### 4. Functions & Scope
Modularizing code and managing memory scope.
* `void` vs return types.
* Parameter passing (by value vs. by reference).
* Function overloading.

### 5. Arrays & Matrices
Handling collections of data.
* One-dimensional arrays.
* Two-dimensional arrays (Matrices) and iteration.

### 6. Structs & File Handling
Custom data types and persistent storage.
* Defining and using `struct`.
* Reading from and writing to text files (`fstream`).

### 7. Object-Oriented Programming (OOP)
Introduction to classes and objects.
* Classes, objects, and attributes.
* Methods and encapsulation.

## 🚀 Advanced Topics

### 8. Pointers & Memory Management
Direct memory manipulation and dynamic allocation.
* Understanding pointers and references (`*` vs `&`).
* Pointer arithmetic.
* Dynamic memory allocation (`new`, `delete`).

### 9. Algorithmic Complexity (Big O)
Analysis of algorithm efficiency.
* Understanding Time vs. Space complexity.
* Big O notation examples ($O(1)$, $O(n)$, $O(n^2)$).
* Best, average, and worst-case scenarios.

### 10. Recursion
Functions calling themselves to solve sub-problems.
* Base cases and recursive steps.
* Recursive vs. Iterative solutions.
* Stack overflow risks.

### 11. Backtracking
Solving problems incrementally and removing invalid solutions.
* Brute-force with pruning.
* Pathfinding and puzzle solving (e.g., N-Queens, Maze solver).

### 12. Linear Data Structures: Lists & Stacks
Dynamic data storage implementation.
* **Singly Linked Lists:** Node structure, insertion, deletion, and traversal.
* **Stacks (LIFO):** `push`, `pop`, and `top` operations. Used for expression evaluation and backtracking support.

### 13. Queues & Deques
Handling ordered data flows.
* **Queues (FIFO):** `enqueue`, `dequeue`, and `front`.
* **Deques (Double-ended Queues):** Insertion and deletion from both ends (Head and Tail).

### 14. Multi-linked Structures
Introduction to non-linear data organization.
* Doubly Linked Lists (pointers to `next` and `prev`).
* Introduction to Trees and Graphs basics.
* Sparse matrices implementation.
